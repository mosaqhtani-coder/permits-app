# تطبيق نظام تصاريح العمل (PWA)

غلاف خفيف يفتح نظام تصاريح العمل (Apps Script) بملء الشاشة كتطبيق على الجوال.

- `config.js`: ضع فيه رابط تطبيق الويب (المنتهي بـ `/exec`) بسطر `APP_URL`.
- الغلاف ما يخزّن أي بيانات تصاريح؛ كل شي يمر على نفس النظام وبنفس الحسابات والصلاحيات.
- يحتاج نسخة Apps Script **v2.37-pwa-embed** أو أحدث (فيها وضع `?embed=1`).
